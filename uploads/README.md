# 网页样本

以后请按站点建子目录上传需要适配的 HTML；netcup 样本放在 `uploads/Netcup/`，绿云放在 `uploads/GreenCloud/`。建议按页面命名，例如 `products.html`、`invoices.html`，并提供对应网址。导出前先关闭汉化及其他翻译扩展并刷新，保留英文原文。

推荐安装项目的 `snapshot-export.user.js`，按 Alt+Shift+E 或在篡改猴菜单中选择“导出当前页面”，省去手动复制 DOM。只采集当前已加载的内容，不自动点击或爬取其他页面；导出包含不少已加载的隐藏下拉菜单，无需每项单独打开。

本目录文件只用于本地分析，不打包进用户脚本，不提交版本库。已有九份样本已原地脱敏。后续样本继续检查并剔除已识别的敏感信息；自动脱敏不能保证覆盖新页面的所有隐私字段，上传前仍请留意姓名、邮箱、地址、客户编号、密钥及令牌。

不要上传密码、Cookie 或 HAR 网络记录。不要直接在浏览器中打开原始样本：它可能包含原站脚本、表单和第三方扩展注入内容。
