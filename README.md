# my_translate

针对指定网站界面的简体中文汉化项目。使用本地词库和站点专属规则，不将页面交给在线翻译服务。

## 安装 / 更新

先安装并启用 Tampermonkey（篡改猴），再打开需要的脚本链接并确认安装：

| 脚本 | 范围 | 安装链接 |
|---|---|---|
| netcup CCP 简体中文 | 概览及六个后台页面 | [安装 / 更新](https://raw.githubusercontent.com/wayner6/my_translate/main/netcup-ccp-zh-cn.user.js) |
| GreenCloud 简体中文 | 登录、客户中心首页及公共导航 | [安装 / 更新](https://raw.githubusercontent.com/wayner6/my_translate/main/greencloud-zh-cn.user.js) |
| 一键脱敏导出 | netcup / GreenCloud 的 HTML 样本采集，按需安装 | [安装 / 更新](https://raw.githubusercontent.com/wayner6/my_translate/main/snapshot-export.user.js) |

保存后刷新目标页面。无需安装 Node.js 或其他依赖。如果链接只显示代码，可手动添加新脚本、粘贴全部内容并保存。netcup 与 GreenCloud 脚本可同时安装，各自只在对应域名运行。

如果没有生效，检查脚本开关、扩展的站点访问权限，并按 Tampermonkey 提示开启“允许用户脚本”或开发者模式。请勿与其他翻译扩展同时翻译同一网站。

更新由 Tampermonkey 按其更新设置检查，也可手动检查或再次打开安装链接。停用脚本后刷新即可恢复原界面。

## 固定文案与变量

只翻译已识别的界面文案。产品名、套餐配置、用户自定义名称、域名、IP、金额、编号、日期及工单正文不作为词条写入。对动态欢迎语只翻译固定前缀，保留姓名；对账单日和更新时间只翻译固定部分，保留数值和时间。

netcup 表格正文默认保留，仅在已知账单状态标签中翻译状态。GreenCloud 产品名称区域、个人资料正文及工单主题不进行词库替换，即使产品恰好叫 `Services` 或 `Login` 也不翻译。

汉化不改变链接、表单提交地址、隐藏字段或用户输入，不点击、不提交、不触发账户操作。下拉选项仅在显式设置 `value` 时翻译显示文字，避免改变提交参数。

## 已适配页面

### netcup CCP

- 公共顶部导航、侧边栏和页脚。
- `/start.php`：概览页的欢迎语、待付账单、论坛关联、Trustpilot 提示、域名核验通知、邮件订阅和招聘文案。
- `/produkte.php`：产品分类筛选、搜索、空列表提示、所有权转移入口。
- `/domains.php`：筛选、搜索、空列表提示、外部域名和订购入口。
- `/rechnungen.php`：筛选、表头、已支付状态、账单日、详情和 PDF 图标提示。
- `/abuse.php`：筛选、搜索及空列表提示。
- `/partnerprogramm.php`：注册条款、复选框说明、注册按钮和条款确认提示。
- `/daten_aendern.php`：资料字段说明、密码修改和已启用 2FA 的界面。
- 支持以上页面的 `/run/` 路径及动态加载的已知词条。

其他标签页、详情页和未知弹窗需要补充样本。Contact 跳转的 netcup 官网不在范围内。

### GreenCloud（绿云）

- `/billing/login`：登录表单、验证码说明、忘记密码入口。
- `/billing/clientarea.php`（无 `action`）：客户中心首页、导航、服务状态、资料卡片标题、工单状态、快捷入口和已知弹窗。
- 公共页眉、导航及页脚；商品系列名称保留英文。
- `clientarea.php?action=...` 是不同子页面，目前不套用首页正文规则，待提供样本后逐页适配。

页面还提供原站的“中文”语言选项；本脚本针对当前英文界面做本地汉化，不修改原站语言设置。图片文字、聊天 iframe、未知页面暂不翻译。

## 一键采集 HTML

1. 安装上表的“一键脱敏导出”脚本。
2. 采集前关闭汉化和其他翻译脚本，刷新，保留英文原文。
3. 打开需要适配的页面，等内容加载完成。
4. 按 **Alt + Shift + E**，或点 Tampermonkey → **导出当前页面**。
5. 浏览器会下载带站点、页面路径和时间戳的 HTML，将其上传到对应本地目录。

一次导出包含当前 DOM 中已加载的文字，包括不少隐藏的下拉菜单，**不需要每个菜单项都点一次**。只有真正打开新页面或通过请求加载新内容的标签页、弹窗，才需要另存状态。导出不会自动点击按钮或自动爬取链接，避免误触付款、删除、重启、退出等操作。

这不是自动遍历全站或批量抓取全部后台。后续如果确有大量只读页面，可以基于明确的安全 URL 清单另做批量采集，不对未知链接盲目抓取。

### 脱敏范围

导出只操作副本、不改变当前登录页面，不上传任何内容。清除：

- 表单输入值、隐藏字段值、密码及验证码内容；
- 已识别的姓名、邮箱、地址、公司、客户编号及产品主机名；
- 个人资料卡片、工单主题、业务表格中的客户数据；
- URL 中的 ID、票据访问码等查询值；
- 脚本、内联事件、data 属性、注释、样式资源、iframe 及浏览器扩展注入物；
- 常见邮箱、IPv4 / IPv6。公开的官方客服邮箱保留。

样本附带脱敏后的页面 URL，并限制脚本、表单和资源加载。它是供分析用的结构样本，不是可操作的网页备份。选项具体值会清除，但是否存在 `value`、原有选择项和 DOM 结构保留。

**自动脱敏不等于已覆盖未知页面的所有隐私格式，分享前仍需检查，尤其是新站点、API 密钥和自定义备注。**所有 HTML 即使脱敏，也不提交公开仓库。后续适配继续检查并清理收到的样本。

## 目录与本地处理

```text
my_translate/
├── netcup-ccp-zh-cn.user.js
├── greencloud-zh-cn.user.js
├── snapshot-export.user.js
├── scripts/sanitize-uploads.cjs   对已知本地样本原地脱敏
├── uploads/                      本地样本，Git 忽略
│   ├── Netcup/
│   └── GreenCloud/
└── tests/                        合成测试及可选本地样本检查
```

后续 HTML 放入对应站点文件夹，附页面 URL；截图只在排版、图片文字或定位问题时需要。

本次已有九份样本已原地清理，不保留未脱敏备份。需要重新处理已知样本时：

```sh
npm ci
npm run sanitize
```

此命令会覆盖 `scripts/sanitize-uploads.cjs` 所列样本，先在内存中完成全部检查再写入文件。脱敏功能只影响采集副本和本地样本，不会清空网站上的表单或账户数据。
