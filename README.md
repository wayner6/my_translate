# my_translate

网站界面简体中文汉化脚本，使用本地词库，不上传页面内容。

## 支持网站

- [netcup CCP](https://www.customercontrolpanel.de/)
- [GreenCloud（绿云）](https://greencloudvps.com/billing/)

## 安装

1. 安装并启用 Tampermonkey（篡改猴）。
2. [安装 / 更新翻译脚本](https://raw.githubusercontent.com/wayner6/my_translate/main/my_translate.user.js)。
3. 刷新目标网页。

## 一键导出（可选）

[安装导出脚本](https://raw.githubusercontent.com/wayner6/my_translate/main/snapshot-export.user.js)，用于提供待适配页面的 HTML。

导出前关闭翻译并刷新，再按 **Alt + Shift + E**，或从篡改猴菜单选择“导出当前页面”。文件包含脱敏后的网址。

自动脱敏可能遗漏特殊字段，分享前请检查个人信息和密钥。
